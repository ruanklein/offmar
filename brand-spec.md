# OffMar visual direction

Native macOS utility, with a file sidebar and a spacious Markdown workspace.
System semantic backgrounds and text adapt to light and dark appearances.

- Accent: warm amber, #B87518 (light), #E4AD56 (dark).
- Typography: SF Pro for controls and headings; SF Mono for Markdown and diagnostics.
- Spacing: 4, 8, 16, 24, 32, 48 points.
- Icons: SF Symbols; no decorative illustrations or gradients.
- Signature detail: a quiet document header with a file-type badge and conversion status.
- Native sidebar selection, toolbar, dialogs, Settings, keyboard shortcuts, and VoiceOver labels.
- All application-authored interface strings are English.
